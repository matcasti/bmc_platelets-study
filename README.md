# Platelet phenotypes, frailty and physical performance in older adults living at high southern latitudes

Analysis code, de-identified analysis data and manuscript sources of the study *Longitudinal associations of platelet
CD41/CD62 phenotypes with frailty and physical performance in older adults living at high southern latitudes*
(Escuela de Medicina, Universidad de Magallanes, Punta Arenas, Chile).

Platelet phenotypes (CD41/CD62, flow cytometry) were related to frailty (FRAIL scale) and physical performance (handgrip
strength, chair sit-to-stand, arm curl and timed up-and-go) in 137 community-dwelling older adults assessed up to three
times over one year, with Bayesian multilevel models (`brms`).

## Quick start

```bash
git clone <repository-url> && cd <repository>
Rscript -e 'install.packages(c("data.table", "here", "brms", "tidybayes", "posterior", "ggplot2", "patchwork", "cowplot",
                                "gtsummary", "smd", "flextable", "officer", "lme4", "scales"))'   # rstan: see below
SKIP_IMPUTATION=1 Rscript run-all.R   # all analyses except the imputation-based models (~30 min) + documents
Rscript run-all.R                     # everything, including the imputation-based models (many hours)
```

Open `platelets-frailty.Rproj` in RStudio or run the scripts from the project root; all paths are resolved with
[`here`](https://here.r-lib.org). [Quarto](https://quarto.org) (>= 1.7) is needed to render the documents.

## Pipeline

| Step | Scripts | Produces | Time |
|---|---|---|---|
| 1. Data and descriptives | `R/01-data/02`-`05` | Table 1, S4, S5, S7, S11 | seconds |
| 2. Main models | `R/02-models/01-main-models.R` | Table S1, Figures 1-2 | ~5 min |
| 3. Sensitivity analyses, observed data | `02-sensitivity-observed-data.R`, `04-conventional-mixed-models.R` | Tables S8-S10 | ~10 min |
| 4. Sensitivity analysis, imputation-based models | `03-imputation-models.R` | Tables S2, S3, S8, S9, S12; Figure S8 | **many hours** |
| 5. Summaries | `R/03-summaries/` | Tables S6, S8-S10 | minutes |
| 6. Figures | `R/04-figures/` | Figures 1-2, S3-S9 | minutes |
| 7. Documents | `quarto render` | the three `.docx` files | ~1 min |

Models are cached in `models/` and refitted only if their data, formula, priors or settings change
(`BRMS_FILE_REFIT=never` loads an existing file as it is; with `SKIP_IMPUTATION=1` the estimates of the imputation-based models are taken from `output/estimates/`). Every model uses seed 1234 and the posterior summaries
reproduce exactly on the same software versions. The imputation-based models (`mi()` terms, 10,000-15,000
iterations, `adapt_delta = 0.999`, `max_treedepth = 50`) take several hours each; everything else runs in minutes.

### Models

| Key | Description |
|---|---|
| `main_frail`, `main_function` | main models: FRAIL score (binomial, 5 trials) and four physical-function tests (multivariate Gaussian), time x (CD41+CD62- + CD41+CD62+ + sex + age + BMI) + participant random intercept, fitted to visits with observed outcomes, covariates and platelets |
| `plt_neg`, `plt_pos` | each platelet percentage across visits (Gaussian, observed values) |
| `cc_frail_bb`, `cc_frail_ord` | alternative FRAIL models: beta-binomial; cumulative-logit for the score collapsed to 0, 1, >=2 |
| `cc_frail_conf`, `cc_function_conf` | + diabetes and statin use |
| `cc_frail_logratio`, `cc_function_logratio` | log-ratio of CD41+CD62+ to CD41+CD62- events |
| `mi_*` | models that estimate missing platelet values within the model (`brms::mi()`): all visits, + total platelet count, log-ratio, participants with platelet data (`_97`), + diabetes and statin use |

## Data

`data/platelets_d.RData` is the dataset used by every script: one row per attended visit (`time`: `t-1` baseline, `t-2`
6 months, `t-3` 1 year). It is de-identified: it contains no names, national identifiers, contact data, free text or
calendar dates (the visit date is given as `visit_day`, days since the start of data collection, and `visit_month`).
Main variables: `id`; `sex`, `age`; anthropometry and body composition (`weight`, `height`, `imc`, `fat_total`,
`muscle_*`, `body_water`, `bone_mass`); blood pressure and heart rate (`bp_*`, `fc`); `frail_total` (FRAIL score 0-5);
physical function (`dinamometer_*`, `sft_cst` chair sit-to-stand, `sft_elbow_flexion` arm curl, `sft_fut` timed up-and-go);
flow cytometry as a percentage of the events of the cells gate (`cd41_{negative,positive}_cd62_{negative,positive}`),
`singlets_pct` (singlets, % of events), `cells_pct` (cells, % of singlets), `plt_10_9_l` (platelet count);
comorbidities and medication (`diabetes`, `hypertension`, `dyslipidemia`, `statins`, ...).

The raw study database (REDCap export, `data/raw/data-raw.csv`) contains direct identifiers and is **not distributed**;
`R/01-data/01-prepare-data.R` documents how the analysis dataset was derived from it
(run it with `PREPARE_DATA=1 Rscript run-all.R` if you hold the database).
